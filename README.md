# To-Do List 
## Deskripsi Aplikasi
To-Do List merupakan aplikasi web sederhana yang digunakan untuk membantu pengguna mencatat dan mengelola daftar pekerjaan sehari-hari.

Aplikasi ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Fitur Aplikasi
1. Menambahkan tugas baru.
2. Menandai tugas yang telah selesai.
3. Menghapus tugas dengan klik dua kali.
4. Menampilkan jumlah tugas.

## Cara Menjalankan Aplikasi
1. Clone repository dari GitHub.
2. Buka folder proyek.
3. Cari file index.html.
4. Buka file index.html menggunakan browser.
5. Aplikasi siap digunakan.
